# Currency Calc Telegram Bot

Телеграм-бот для получения актуальных курсов валют по отношению к российскому рублю (RUB). Данные запрашиваются в реальном времени через внешний сервис ExchangeRate-API.

## Функциональность

- Получение курса введенной валюты к рублю по ее стандартному коду (например, USD, EUR, JPY).
- Команда `/start`: приветствие и краткая инструкция по использованию.
- Команда `/list`: вывод справочного списка популярных кодов валют.
- Базовая обработка ошибок при вводе некорректных кодов или сбоев сети.

## Технологический стек

- Язык: Java 24
- Фреймворк: Spring Boot 3.5.4
- Система сборки: Maven
- Основные зависимости: 
  - `telegrambots-springboot-longpolling-starter` (взаимодействие с Telegram API)
  - `Lombok` (сокращение шаблонного кода)
  - `org.json` (парсинг ответов от внешнего API)

## Требования для запуска

1. Установленная JDK 24 или выше.
2. Токен Telegram-бота (получается у @BotFather).
3. API-ключ от сервиса ExchangeRate-API.

## Конфигурация и запуск

Необходимые ключи указываются в файле конфигурации `application.properties` или передаются через переменные окружения:
- `telegram.bot.token`
- `currency.token`

Для сборки и запуска проекта используйте Maven Wrapper:

```bash
./mvnw spring-boot:run
```

Для сборки исполняемого jar-файла:

```bash
./mvnw clean package
```
